# Project Screenshots

This directory contains screenshots captured during the AWS Enterprise IAM Lab.

The screenshots provide visual evidence of the IAM configuration and access-control testing completed during the project.

## Included Screenshots

### 01-IAM-User-Groups.png

Shows the IAM user groups created for the lab, including groups such as:

- Developers
- CloudEngineers
- Interns
- SecurityAdmins

### 02-IAM-Users.png

Shows the IAM users created for the project.

### 03-Alice-Console-Access.png

Shows console access configuration for the `alice.dev` IAM user.

## Purpose

These screenshots support the project documentation by providing evidence of:

- IAM user creation
- IAM group creation
- IAM console access
- Group-based access management
- Practical AWS IAM implementation

Additional screenshots may be added as the project expands.
